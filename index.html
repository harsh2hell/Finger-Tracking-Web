Quick Start Guide

1

Start Dashboard Camera

Navigate to the Dashboard tab, and click Start Camera to stream your webcam feed.

2

Configure Profiles

Head to the Profile tab to customize actions (like pressing Arrow Keys or Muting) for specific hand gestures.

3

Enable Automation

In the Settings tab, toggle Enable OS Controls to active. Your hands will now interact with your OS!

About TrackOS

TrackOS leverages local Google MediaPipe models directly inside the browser rendering shell. All AI computations are executed on-device, meaning zero latency, zero cloud uploads, and complete user privacy.

Version 2.0 Enhancements:

  • • Multi-hand tracking engine (up to 2 hands)
  • • Reliable thumb detection with handedness rules
  • • Floating wrist HUD card overlays & pulsing target rings
  • • Secure IPC integration for Windows and macOS automation

Gesture Mappings Configuration

Customize what native OS events are fired when hand gestures are sustained.

Gesture System Action Keyboard / Event Simulation Action Trigger Description
Victory Sign Right Arrow Ideal for navigating forward in presentations (slides)
Index Finger Left Arrow Ideal for navigating backward in presentations (slides)
Thumbs Up Volume Up (+6%) Raises audio volume when held
Thumbs Down Volume Down (-6%) Decreases audio volume when held
Fist Audio Mute Toggles system audio volume on/off
Rock On N/A Custom toggle for shortcuts

Note on Cooldown: Navigation commands (like Arrow Keys) have a built-in 800ms cooldown to prevent rapid trigger cycling. Volume commands auto-fire every 250ms when held.
